# Submission review

The public source directory and every member of all 107 companion ZIP assets
were inspected. The Release data contain 1,787 members, including read-only
backups of 34 completed frontier databases. Archive paths are relative and
archive timestamps are normalized.

The final scan found no local account or installation paths, Korean text,
private credential patterns, or excluded derivative-intersection experiments.
Compiled executables, generated Python bytecode, internal review reports,
local operational logs, upstream Git history, and the working paper PDFs are
excluded. Generated cache files were removed after execution checks.
The exported comparison PDF has an empty author field and no creation or
modification date metadata.

Author and external-link review found generic submission attribution and
legitimate upstream credits. Third-party author names, project links, and
license notices are preserved. They are not author identities for this
submission. All documentation, labels, and included first-party text are in
English; mathematical notation and proper names are retained.

`VALIDATION.json` records the execution checks and their limits. Archived
exact/candidate status remains explicit, and the five unfinished cases retain
intervals. Revised-paper upper reports, independent original-lattice BKZ
witnesses, and lifting-derived upper witnesses are kept separate.

This is a file-content review of the prepared artifact. It cannot establish
the anonymity of the GitHub account, commit author identity, publication
settings, or future uploads. The directory contains no submission Git history.
Automated pattern checks complement the manual review; they do not guarantee
that arbitrary mathematical data can never be correlated with another source.
